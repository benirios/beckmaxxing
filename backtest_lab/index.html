THE NEXT CHAPTER

Better questions.
Stronger evidence.

Ideas for the next versions of the research desk. These are proposed improvements, not features that are already running.

01 / COMPARISON

Compare runs on equal terms

Overlay normalized curves, match test windows and costs, and compare a strategy with its baseline or placebo.

See what changed, and whether it helped.
02 / DATA QUALITY

Make coverage visible

Show missing tick intervals, session coverage, warmup, and the difference between requested and observed costs beside each result.

Know what the backtest actually observed.
03 / TRADE ANALYSIS

Inspect every trade

Browse entries and exits, holding times, fees and stop reasons. Add monthly returns, drawdown duration and profit/loss distributions.

Understand what drives the equity curve.
04 / VALIDATION

Separate discovery from validation

Freeze rules and test windows before evaluation. Add walk-forward comparisons and uncertainty estimates without repeatedly tuning on the holdout.

Measure whether a result survives new data.
05 / WORKFLOW

Queue frozen experiments

Plan a bounded sequence of tests with declared inputs, provenance and controls. Keep one native execution at a time and preserve each failed attempt.

Spend less time managing the runner.
06 / SHARING

Export the research

Download comparison tables, trade CSVs and concise run summaries with source hashes, data mode and audit issues attached.

Make findings easier to review and reproduce.
BEFORE ADDING MORE STRATEGIES

Improve the evidence behind the ranking: comparable test periods, enough trades, verified costs and independent validation. A high return/drawdown score is a useful sorting tool; it is not a deployment decision.
