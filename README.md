A plataform to agentic backtest using historical tick data from Ctrader.
##How it works?
The beckmaxxing platform pulls historical tick data using the Trader CLI for a more agentic optimized backtesting of Cbot algorithms.

##Objective
The objective is to let your desired CLI to run backtests of trading algos based on papers, trading hypothesis in a autonomous system.
A /Goal will let you off the charts for a bit while Codex/Claude doebs the rest until it finds a real Edge.

##Why it exists?
It came from the pain of running backtests manually for hours a day without without any real result coming out of it.
